# ホールデム道場 (Hold'em Dojo)

テキサスホールデムの学習アプリ。単一の `index.html` で動作（外部ライブラリなし、Google Fonts のみ）。

- GTOドリル（プリフロップ RFI / vs オープン / vs 3ベット、混合戦略の頻度採点）
- レンジ表ブラウザ
- フロップ Cベット判断（ヒューリスティック）
- ハンド履歴レビュー（PokerStars 形式テキストを解析）
- 役の強さ / アウツ・ポットオッズ / エクイティ計算 / 用語集

公開: GitHub Pages（`publish_pages.py` で push）。レンジは公開チャート由来の近似であり、ソルバーの厳密解ではありません。
